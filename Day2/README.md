# Day 2 – Logic Gates

Today I learned about some basic logic gates and their Verilog operators.

1. NOT gate – `~a`  
   Output is 1 when a is 0.

2. AND gate – `a & b`  
   Output is 1 only when both inputs are 1.

3. OR gate – `a | b`  
   Output is 1 when any one of the inputs is 1.

4. XOR gate – `a ^ b`  
   Output is 1 when the two inputs are different.

5. NOR gate – `~(a | b)`  
   Output is 1 when both inputs are 0.

6. XNOR gate – `~(a ^ b)`  
   Output is 1 when both inputs are the same.

I practiced these operators in Verilog.
